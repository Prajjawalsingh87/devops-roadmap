# Study log

Use one entry for each hands-on session. The published guides live in
`aws-iam/` and `nginx/`; the README distinguishes completed guides from planned topics.

| Date | Topic | What I tried | Evidence / result | Next question |
|---|---|---|---|---|
| YYYY-MM-DD | Topic name | Small reproducible exercise | Sanitized command output or link | What to investigate next |

## Session checklist

- Write the expected outcome before running the exercise.
- Record the actual result, including failures and their cause.
- Remove account IDs, credentials and personal data from shared evidence.
- Clean up temporary cloud resources after the exercise.
- Link the relevant guide and the next exercise.

This is a template, not a record of completed work.
